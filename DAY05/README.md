# Password Generator 🔐

This project is part of **Day 5** of the *100 Days of Code – Python* challenge.

---

## 📌 Topics Covered

- `for` loops
- `range()` function
- Python lists
- Randomisation using the `random` module
- String construction using loops

---

## 🛠 Project Description

The **Password Generator** program creates a secure password based on user preferences.

The user specifies:
- Number of letters
- Number of symbols
- Number of numbers

The program then randomly selects characters, shuffles them, and generates a strong password.
