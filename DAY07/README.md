# Day 7 – Hangman Game

## 📌 Overview
This project is a text-based **Hangman game** built using Python.  
It focuses on breaking a complex problem into smaller logical steps and implementing them using core Python concepts.

The game randomly selects a word, and the player must guess the letters correctly before running out of lives.

---

## 🧠 Concepts Covered
- Problem decomposition using flowcharts
- Random module
- Lists and strings
- Conditional statements (`if / else`)
- Loops (`while`)
- Tracking state using variables
- User input validation
- Game logic and control flow

---

## 🎮 Project Description
- A random word is selected from a predefined list
- The player guesses one letter at a time
- Correct guesses reveal letters in the word
- Incorrect guesses reduce available lives
- The game ends when:
  - The player guesses the word correctly (WIN)
  - The player runs out of lives (LOSE)
