# Treasure Island 🏝️

This project is part of **Day 3** of the *100 Days of Code – Python* challenge.

---

## 📌 Topics Covered

- Control flow using `if`, `elif`, and `else`
- Nested conditional statements
- Logical operators (`and`, `or`, `not`)
- Modulo operator
- User input and decision-based logic

---

## 🎮 Project Description

**Treasure Island** is a text-based adventure game where the user makes decisions at different stages of the game.

Based on the choices entered by the user, the program uses conditional logic to determine whether the player progresses, wins, or loses the game.

---

## ✅ Learning Outcome

This project helped in understanding:
- Writing decision-based programs
- Structuring logic using conditional statements
- Combining multiple conditions using logical operators
- Controlling program flow based on user input
