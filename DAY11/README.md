# Day 11 – Blackjack Capstone Project

## Topics Applied
- Functions and function calls
- Return values
- Conditional logic
- Lists and dictionaries
- Random module
- Code refactoring
- Game flow control

## Project
### Blackjack Game
A command-line Blackjack game that:
- Deals cards randomly to user and computer
- Calculates scores using game rules
- Handles Blackjack and bust conditions
- Allows player to hit or stand
- Refactors logic into reusable functions

## Key Learnings
- Breaking a large problem into smaller functions
- Writing clean and readable game logic
- Using functions to manage game state
- Applying real-world rules in code
