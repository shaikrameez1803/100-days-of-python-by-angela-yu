# Rock Paper Scissors ✊✋✌️

This project is part of **Day 4** of the *100 Days of Code – Python* challenge.

---

## 📌 Topics Covered

- Randomisation using the `random` module
- Python lists
- Indexing and accessing list elements
- Nested lists
- Handling index-related errors

---

## 🎮 Project Description

The **Rock Paper Scissors** game is a simple console-based game where the user competes against the computer.

The computer randomly selects an option using the `random` module, while the user provides their choice.  
The program then compares both choices and determines the winner based on predefined game rules.

---

## ✅ Learning Outcome

This project helped in understanding:
- How to generate random values in Python
- How to store and access data using lists
- How to map indexes to meaningful values
- Implementing simple game logic using Python
