## Day 13 – Debugging in Python

## Topics Covered
- Describing the problem clearly
- Reproducing bugs consistently
- Playing computer (step-by-step execution)
- Identifying syntax, logic, and runtime errors
- Using print() statements for debugging
- Using a debugger to trace execution
- Watching IDE error highlights and warnings

## Practice Exercises
- Debugging Odd or Even program
- Debugging Leap Year logic
- Debugging FizzBuzz program

## Key Learnings
- Debugging is a skill, not guessing
- Reading error messages carefully saves time
- Step-by-step execution reveals logic flaws
- Debuggers help visualize program flow
