## 🛠 Project: Secret Auction
A console-based auction program where multiple users can place bids anonymously.
The program stores bids in a dictionary and determines the highest bidder at the end.

## 🧠 Key Learnings
- How dictionaries store and manage related data
- How to compare values inside a dictionary
- How to clear the screen and continue program flow
- Writing clean logic for real-world scenarios
