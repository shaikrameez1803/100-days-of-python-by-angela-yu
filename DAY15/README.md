# Day 15 – Coffee Machine Project

## Project
Coffee Machine (CLI Simulation)

## Concepts Used
- Local development environment setup
- Python functions
- While loops
- Conditional logic
- Dictionaries for resources and menu
- State management
- User input handling

## Project Description
This project simulates a coffee machine using Python.
The program handles user commands, manages resources,
processes transactions, and delivers coffee based on availability.
It mimics a real-world machine workflow in a command-line interface.

## Key Learnings
- Breaking a large problem into smaller functions
- Managing shared data using dictionaries
- Writing structured, readable code
- Building real-world logic-based simulations
