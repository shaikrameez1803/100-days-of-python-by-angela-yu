# Day 17 – Quiz Project & Benefits of OOP

## Topics Covered
- Creating custom classes in Python
- Constructors and the __init__() method
- Adding and using class methods
- Object interaction and state management
- Understanding benefits of Object Oriented Programming
- Using external data sources (Open Trivia DB concept)

## Project
Quiz Application (OOP Based)

## Description
On Day 17, a complete quiz game was developed using Object
Oriented Programming. The project involved creating multiple
classes to separate responsibilities such as storing questions,
handling quiz logic, displaying questions, validating answers,
and tracking user score.

## Key Learnings
- Designing programs using multiple interacting classes
- Cleaner and more maintainable code using OOP
- Improved scalability and readability
- Real-world application structure using Python
