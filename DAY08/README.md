## 🛠 Project: Caesar Cipher
A simple text-based encryption program that shifts letters forward by a fixed number
to encode a message. The same logic can be reused for decryption by reversing the shift.

## 🧠 Key Learnings
- How to pass values into functions
- How functions improve code readability
- How to loop through strings and shift characters
- How to organize logic into reusable blocks
