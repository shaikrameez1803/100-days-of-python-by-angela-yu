# Tip Calculator 💰

This project is part of **Day 2** of the *100 Days of Code – Python* challenge.

---

## 📌 Topics Covered

- Data types (`int`, `float`, `string`)
- Type conversion
- Arithmetic operations
- User input and output

---

## 🧮 Project Description

The **Tip Calculator** program:
- Takes the total bill amount from the user  
- Accepts the tip percentage  
- Splits the bill among multiple people  
- Calculates the amount each person should pay
