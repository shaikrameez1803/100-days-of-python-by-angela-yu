# 🎮 Day 19 – Turtle Etch-A-Sketch App

This project is part of the **100 Days of Code – Python Bootcamp**.

## 📌 Project Overview
Built an interactive Etch-A-Sketch style drawing application using Python Turtle graphics.

Users can control the turtle using keyboard inputs to draw on the screen.

## 🚀 Features
- Move forward
- Move backward
- Turn left
- Turn right
- Clear screen and reset drawing

## 🧠 Concepts Practiced
- Higher Order Functions
- Event Listeners
- Object State
- Instances in Python
- Turtle Coordinate System
- Keyboard key bindings

## 🛠 Technologies Used
- Python 3
- Turtle Graphics Module

## 📚 What I Learned
- How to bind functions to keyboard keys
- How instances maintain state
- How coordinate positioning works in graphical systems
- Structuring interactive programs
