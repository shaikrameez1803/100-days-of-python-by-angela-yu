## Project
### Number Guessing Game
A console-based game where:
- The computer selects a random number
- User guesses the number within limited attempts
- Difficulty levels control number of guesses
- Scope is used correctly to manage game variables

## Key Learnings
- Understanding how Python resolves variables
- Avoiding common scope-related bugs
- Writing cleaner code using functions and constants
- Applying scope rules in a real project
