# Day 16 – Object Oriented Programming (OOP)

## Topics Covered
- Why Object Oriented Programming is needed
- Classes and Objects
- Attributes and Methods
- Constructors (__init__)
- Accessing and modifying object data
- Installing and using external Python packages
- Applying OOP to a real-world project

## Project
Coffee Machine (OOP Version)

## Description
This day focused on transitioning from procedural programming
to Object Oriented Programming. The Coffee Machine project
was restructured using classes to improve code organization,
readability, and scalability.

## Key Learnings
- How OOP models real-world entities
- Encapsulation of data and behavior
- Writing reusable and maintainable code
- Understanding how objects interact in a program
