# Escaping the Maze 🧩

This project is part of **Day 6** of the *100 Days of Code – Python* challenge.

---

## 📌 Topics Covered

- Defining and calling Python functions
- Code indentation and structure
- `while` loops
- Loop-based problem solving
- Writing reusable logic using functions

---

## 🛠 Project Description

The **Escaping the Maze** project focuses on navigating a character through a maze using logical rules.

The solution uses:
- Custom functions to organize repeated actions
- `while` loops to handle continuous movement
- Conditional logic to make decisions based on the environment

This project is implemented using the **Reeborg’s World / Karel-style environment** provided in the course.

---

### ✅ Learning Outcome

This project helped in understanding:
- How to break problems into reusable functions
- The importance of proper indentation in Python
- Using `while` loops for repeated actions
- Solving logical challenges step by step
